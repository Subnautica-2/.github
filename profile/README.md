Subnautica 2 is a survival exploration game set in a vast alien ocean world, expanding on the original experience with new environments, mechanics, and deeper gameplay systems. Players dive into unknown waters, uncover secrets, and survive in a dangerous yet beautiful underwater ecosystem.
